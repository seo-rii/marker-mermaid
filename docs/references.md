# Research and implementation references

The MMX-001 v0.3 design incorporates ideas from the following public research and
implementations.

| Source | Concept used by this project |
| --- | --- |
| [Flowchart2Mermaid](https://arxiv.org/abs/2512.02170) | Mixed-initiative review workflow |
| [EdgeFlow](https://arxiv.org/abs/2605.27332) | Edge-map priors, path evaluation, and bounded iteration |
| [Arrow-Guided VLM](https://arxiv.org/abs/2505.07864) | Arrow endpoint and direction overlays |
| [BPMN-VLM](https://arxiv.org/abs/2511.22448) | Structure-first extraction with OCR label enrichment |
| [Reference-Free Evaluation](https://arxiv.org/abs/2602.13376) | OCR recall and entailment precision |
| [FlowPathAgent](https://arxiv.org/abs/2506.01344) | Node and path provenance |
| [FlowLearn](https://arxiv.org/abs/2407.05183) | Ensemble design and multimodal evaluation |
| [FlowVQA](https://arxiv.org/abs/2406.19237) | Directionality and logical-progression evaluation |

The Mermaid runtime implementation follows the official documentation:

- [Usage: parse and render](https://mermaid.js.org/config/usage)
- [Mermaid API interface](https://mermaid.js.org/config/setup/mermaid/interfaces/Mermaid.html)
- [Security level](https://mermaid.js.org/config/schema-docs/config-properties-securitylevel.html)
- [Configuration schema](https://mermaid.js.org/config/schema-docs/config)
